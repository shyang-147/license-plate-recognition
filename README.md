# 车牌识别 · MATLAB 工程实例 + 免安装网页版

中国大陆车牌（蓝底白字 / 新能源绿牌 / 黄底黑字 / 白底警用）照片识别的完整实现。
一条流水线 —— **车牌定位 → 倾斜校正 → 字符分割 → 字符识别** —— 三种交付形态，
算法与参数一一对应。

![网页版界面：上传照片后给出车牌号、逐字符置信度与中间过程](site/screenshot.png)

## 三种形态

| 目录 | 形态 | 需要装什么 | 适合场景 |
|---|---|---|---|
| [`matlab/`](matlab/) | MATLAB 工程本体（识别内核） | MATLAB R2024b + Image Processing Toolbox | 课程设计 / 毕设、讲清算法、调参 |
| [`site/`](site/) | **单文件网页版**（一个 `index.html`） | 什么都不用装，浏览器打开就行 | 随手试用、发给别人看 |
| [`server/`](server/) | Python + MATLAB 后台版 | Python 3 + MATLAB | 局域网 / 公网给多台设备用 |

网页版是把 `matlab/` 的流水线用 JavaScript 重写，字符模板直接从 `matlab/templates.mat`
导出（31 汉字 + 24 字母 + 10 数字 + 5 个特殊字 `警挂学领使`），所以两版识别结果基本一致。

## 算法流程

![MATLAB 流水线逐级调试图](docs/matlab-pipeline.png)

| 步骤 | 文件（MATLAB） | 做法 |
|---|---|---|
| ① 车牌定位 | `locatePlate.m` | 蓝/绿/黄底色掩膜 + Sobel 边缘掩膜 + 形态学闭运算连成候选块；按长宽比、面积、底色占比、边缘密度、矩形度打分取最优；颜色/边缘两路都没找到真车牌时，再走一路**白底车牌**兜底（警用） |
| ② 真车牌闸门 | `locatePlate.m` | 矩形度 < 0.50、框内底色占比 < 0.30 或**框内垂直边缘密度 < 0.02**（框里必须有成排的字）直接判为假车牌，返回"未检测到"（防蓝色广告牌、纯色车身误检）；白底通道另用一套：白底占比 ≥ 0.35 + 边缘密度 ≥ 0.02 + 矩形度 ≥ 0.40 |
| ③ 几何校正 | `correctPlate.m` | 取车牌掩膜的四个极值点当四角：四角明显是梯形时用单应变换拉正（**透视校正**），否则沿用"上下边界拟合倾角 → 反向旋转"；统一高度归一到 64 px |
| ④ 字符分割 | `segmentChars.m` | CLAHE 增强 → Otsu 二值化 → 清除车牌外框/边框残留 → 垂直投影切字符段 → **按"间距均匀度"自校准字符数（6~8，兼容新能源 8 位牌）** → 归一化，同时输出每段墨迹宽高比 |
| ⑤ 字符识别 | `recognizeChars.m` | 单字符归一化到 32×16 → 降采样 24×12 特征 → 与模板库比对 `0.65×IoU + 0.35×相关系数`；**按 `plateFormat.m` 逐位限定候选字符集**（第 1 位汉字 / 第 2 位字母 / 新能源第 3 位字母 / 其余字母数字），极细长的墨迹偏向数字 `1`，首位置信度 < 0.45 输出 `*` 占位 |

**分辨率退化曲线**（合成退化集 60 张，`bench_stage` 逐档归因；第八轮把识别侧低分辨率增强做掉之后）：

| 车牌宽 | 220 | 180 | 150 | 125 | 105 | 90 | 75 | 60 | 48 | 38 |
|---|---|---|---|---|---|---|---|---|---|---|
| 整牌 | **100%** | **100%** | 66.7% | 50.0% | 66.7% | 0 | 0 | 0 | 0 | 0 |
| 字符 | **100%** | **100%** | 93.2% | 93.2% | 95.5% | 54.5% | 29.5% | 0 | 2.3% | 4.5% |
| 定位(IoU≥.5) | 100% | 100% | 100% | 100% | 100% | 100% | 100% | 83.3% | 83.3% | 83.3% |

第七轮的曲线是「识别在 105~180 px 先崩」；第八轮把这段填平（w180 整牌 66.7% → **100%**），
悬崖**下移到 90 px**，而且性质变了 —— 90 px 以下的失败开始是**分割**的账（字符数就不对）。
真实照片那 3 张：定位 **3/3 全中**（IoU 0.655 / 0.836 / 0.774），失败都在识别/分割边界。

**CCPD 真实照片集（第八轮）**：把分辨率这一维控制住之后，差出来的就不是分辨率了 ——
同样 180~220 px 宽的车牌，上面那张自产退化曲线是 **100%**，CCPD 只有 **6.3%**（定位命中后 13.5%）。
差的那 90 个点全在「域」上：对比度低、模糊、字体与白边框画法不同、拍摄角度。
定位命中之后**切出来的字符数也只有 55.8% 是对的**，即「框对了识别仍然不行」。
另外 40 张真实无车牌照片上误检 **23/40** —— 第六轮那套「结构证据闸门」挡得住纯噪声（0/8），
挡不住汽车照片里的像车牌的矩形。详见 [`docs/改进记录.md`](docs/改进记录.md) 第八轮。

怎么读这张表：

- **合成集上的数字不能外推**：bench / hard 都是合成图，字体与模板同源，属于"自己考自己"，
  只用来做回归自查 —— 定位、几何校正、去外框、字符分割在这些图上已经稳定
  （bench 字符数 100%、首位汉字 100%）。
- **剩下的瓶颈是斜拍与形近字符**：难集里 6 张斜拍图只有 1 张整牌全对，错的多是
  `9↔X`、`6↔8` 这类形近字符；透视拉正能让笔画看清楚，但拉正时的插值模糊又会拖累模板匹配。
- **真实照片的瓶颈分三层**：定位（车牌被别的色块挤掉）、分割（车牌自带的边框线会把
  垂直投影连成一条）、分辨率（车牌只有 93 px 宽，单字 8×12 px）。近景实拍（车牌占满画面）
  已经能整牌全对，远距离 / 小目标路拍仍是 0/3。
- **CCPD 那 360 张是本项目唯一的「外部考试」**：bench / hard / degrade 全是自产图，
  字体与 `templates.mat` 同源，属于「自己考自己」；CCPD 是真照片、真字体、真光照。
  它给出的 6.7% 字符率**不代表**系统的真实水平（相机/城市/时段都和样图不同），
  但比「3 张真图算出来的 50%」可信得多 —— 至少它证明了瓶颈在**二值化/分割**，
  不在模板数量，也不在分辨率。
- **两版引擎的数字不一样是正常的**：MATLAB 用 `adapthisteq + Otsu`，网页版用
  `illumNormalize + Otsu`，二值化后笔画的胖瘦不同，连"特征二值化阈值"这种调参常数
  两版也不同（MATLAB `0.5`、网页版 `0.35`，各自的实测依据都写在代码注释里）。
  改任一侧参数前，请把 MATLAB 自检和网页版端到端测试都重跑一遍。

## 已知限制

- 只认**中国大陆**车牌。蓝/绿/黄底色走颜色掩膜；**白底警用车牌**走「边缘掩膜 + 白色掩膜」
  的兜底通道，军用 / 使领馆牌没有实测过。⚠️ 白底通道的主要风险是白色车身、白墙、白底广告牌：
  目前靠「框内必须有成排的字 + 长宽比 ≤ 3.8」挡住，但「白底 + 成排黑字 + 长宽比 3 左右」
  的牌子仍然分不出来。
- ~~纯随机噪声图会误检~~ **已修（第六轮）**：680×1000 的纯噪声图最多时有 22/30 个种子会骗过
  真车牌闸门、报出凭空捏造的车牌号（第四轮起的老问题）。第六轮给闸门补了「结构证据」
  （框里得切得出成排的字），实测 680×1000 与 90×90 的纯噪声图都是 **0/30**，
  且 50 张有车牌图**逐图逐字节不变**。有结构的干扰图（蓝天 / 棋盘格 / 文字 / 路面 / 夜景）本来就挡得住。
- 字符识别是模板匹配，形状相近字符（`1/4`、`9/X`、`3/V`）易混；要更准请走
  `train_char_cnn.m` 训练 CNN，用 `recognizeCharsCNN.m` 替换。
- **低分辨率失败在哪一步，已经按档扫过一遍**（第七轮）：合成退化集把车牌宽从 220 px 扫到 38 px，
  整牌 100% → 0%；**字符率 180 px 就开始掉**（100% → 95.5%）、90 px 掉到 27.3%、
  而**定位一直撑到 60 px** 才出现失败。也就是低分辨率下先崩的是**识别**、再是**分割**，
  定位反而是最后倒的 —— 优化优先级别放错。
- **斜拍是弱项**：透视校正只在车牌被拍成明显梯形时才启用（否则退回旋转校正），
  难集里 6 张斜拍图只有 1 张整牌全对（MATLAB 1/6，网页版 0/6）。
- **真实照片要分两类看**：近景实拍（车牌占满画面）修好外框白线后已经能整牌全对
  （`苏A1085K` 7/7）；远距离 / 小目标路拍（车牌几十像素宽）整牌仍是 0/3。
- 照片里车牌宽度至少 100 px；太远、太糊、过曝、夜拍、反光都会显著掉准确率。
- 照片里不要出现其它蓝底/绿底矩形物体（蓝色广告牌、蓝色车身），否则第一步可能定位错。
- 字符数是**自校准**的（7/8 位自适应）：bench 上分割正确率 100%、hard 上 91.7%，
  hard 里剩下那 2 张都是斜拍样本。
